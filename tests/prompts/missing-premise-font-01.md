# テストプロンプト：前提欠落（missing-premise-font-01）

## 類型

前提欠落（requirements.md 11.1節）— CJK文言かつフォント未同梱

## 実行前提（テスト環境）

- Unityプロジェクトが存在する（`Assets/`・`ProjectSettings/`とも存在）。
- `Assets/Resources/`配下に、日本語（CJK）表示に対応するフォントファイル（`.ttf`・`.otf`）もTMPフォントアセットも存在しない。

## 要求文

```
日本語のメニュー画面を新規に作ってください。「設定」「サウンド」
「ことば」の3つの項目をボタンで並べ、選択すると各設定画面に遷移
します。文言はすべて日本語で表示してください。
```
