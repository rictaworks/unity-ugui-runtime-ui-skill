# テストプロンプト：発火・構築（fire-build-01）

## 類型

発火・構築（requirements.md 11.1節）

## 実行前提（テスト環境）

- 対象ディレクトリはUnityプロジェクト（`Assets/`・`ProjectSettings/`の双方が存在する）。
- `Assets/`配下に既存のUI共通基盤（`UiTheme`・`UiFactory`・`UiScreenBase`相当のクラス）は存在しない。
- `Assets/Resources/Fonts/`配下に日本語（CJK）表示に対応したフォントファイル（`.ttf`）が既に配置されている。
- 環境変数`UNITY_PATH`は未設定（検証段階は静的検査段階になる想定）。

## 要求文

```
Unity（WebGL）向けの在庫確認画面をuGUIのコードのみで新規に作成してください。
所持しているアイテムをScrollRectで一覧表示し、通信中はローディング表示、
アイテムが1件も無いときは空状態の表示、取得に失敗したときはエラー表示を
出してください。画面右上に閉じるボタンを置き、解像度やアスペクト比が
変わっても崩れないようにしてください。文言は日本語で表示します。
```
